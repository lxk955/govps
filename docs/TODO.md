# GoVPS 待办事项与路线图 (Roadmap & TODO)

## 监控探针 (Monitor Agent)

### [ ] 远期扩展预研：Go 原生静态编译 Agent

- **定位与考量**：
  当前纯标准库 Python 3 探针已实现零外部依赖、秒级热重载与全架构自适应，在 512MB 及以上主流 VPS（搬瓦工、DMIT 等）上运行极其轻量（常驻 RSS 约 12MB ~ 18MB，CPU < 0.1%）。
  若后续规划支持 OpenWrt 软路由、嵌入式设备，或收集到较多 64MB/128MB 特种微型小鸡无法安装 Python 3 的反馈，可考虑规划 Go 原生静态编译版本。
- **真实指标预期**：
  - 基于 Go 语言静态编译（`CGO_ENABLED=0`，零 libc 依赖）。
  - 因包含 TLS 协议栈与系统 CA 证书池，空闲常驻内存真实预期约 **6MB ~ 12MB**（相比 Python 节省约 5MB ~ 10MB），主要解决极端轻量系统环境免装 Python 的便利性。
- **触发启动条件**：
  1. 用户群体对 OpenWrt、软路由、无 Python 环境的极简 Alpine / 容器有明确且规模化的监控诉求。
  2. 搭建好完善的 GitHub Actions 跨架构编译（amd64/arm64/armv7 等）与高可用 CDN / 镜像分发源。
  3. 采用单轨替换而非双轨维护，避免两套探针行为分叉导致排障成本倍增。
